# Plan: Gotar – fase 2

**Oprettet:** 22. oktober 2026
**Status:** Fase 2D færdig
**Spiltitel:** Gotar

## Vision

Gotar er et roligt pasningsspil til 3. klasse. Man laver sin figur, vælger et
æg, udklækker sit kæledyr og passer det i hjemmet og byen. Der er ingen timere,
ingen "game over" og ingen måde at ødelægge sit spil på. Omsorg giver hjerter,
hjerter køber ting, og ting gør hjemmet og kæledyret sjovere.

## Kerne-loop

1. Se kæledyrets behov i HUD'en.
2. Giv mad, leg, kæl eller sov.
3. Behovene stiger, og man tjener hjerter.
4. Køb møbler, legetøj, godbidder og tilbehør.
5. Indret huset og tag kæledyret med i byen/parken.
6. Kom hjem og fortsæt – alt gemmes automatisk.

## Designprincipper

- Ingen tab, ingen straf, ingen ventetid. Eleven kan altid rette op.
- Behov falder kun, mens man spiller – ikke i realtid.
- Store trykflader (min. 64 px), ikoner + korte danske tekster.
- Maks. 2–3 tryk til en handling. Ingen hover-afhængighed.
- Al dansk tekst i `src/game/text.ts`, kode og filnavne på engelsk.
- Alt gemmes lokalt. Ingen konto, reklamer eller netværk.

## Spilflow

```text
Menu
 ├─ Fortsæt → Hjem (hvis kæledyr findes)
 └─ Nyt spil → Karakter → Vælg æg/kæledyr → Udklækning → Hjem
                                                         ├─ Indret huset
                                                         ├─ Bykort → Butik
                                                         └─ Bykort → Parken
```

Hvis man afbryder undervejs: figur gemmes straks; mangler kæledyret, starter
"Fortsæt" ved ægvalget.

## Karakter

Én editor-scene med live-preview og faner.

| Fane    | Valgmuligheder                                 |
| ------- | ---------------------------------------------- |
| Hud     | 4 hudtoner                                     |
| Hår     | 5 frisurer × 6 farver                          |

Alle lag tegnes i samme koordinatsystem. Hud, hår og tøj males i lys grå/hvid
og farves med `setTint`, så antallet af SVG-filer holdes nede.

## Behov og omsorg

| Behov  | Fald        | Handling | Effekt | Hjerter |
| ------ | ----------- | -------- | ------ | ------- |
| Mæthed | −1 pr. 18 s | Giv mad  | +35    | 2       |
| Glæde  | −1 pr. 24 s | Leg      | +30    | 3       |
| Glæde  |             | Kæl      | +15    | 1       |
| Energi | −1 pr. 36 s | Sov      | +40    | 1       |

- Handlingen giver kun hjerter, hvis behovet faktisk stiger.
- Humør = gennemsnit: glad ≥ 75, okay ≥ 40, trist < 40.
- Tristhed ændrer kun udtryk og viser et behovsikon – ingen konsekvenser.
- Mad er altid gratis ved madskålen; godbidder i butikken er bonus.

## Økonomi

- Start: 20 hjerter.
- Omsorg giver 1–3 hjerter; parkture og små opgaver giver lidt mere.
- Butik: møbler, legetøj, tilbehør og godbidder. Priser ca. 5–80 hjerter.
- Man kan ikke gå i minus. Køb bekræftes med en tydelig knap.

## Save v2

```ts
interface SaveData {
  version: 2;
  settings: { sound: boolean };
  player: { look: CharacterLook } | null;
  pet: {
    id: PetId;
    name: string;
    needs: { hunger: number; joy: number; energy: number };
    bond: number;
    hatchedAt: number;
  } | null;
  wallet: { hearts: number };
  inventory: Record<string, number>;
  home: { furniture: PlacedFurniture[] };
  flags: { tutorialDone: boolean };
}
```

- `parseSave` accepterer v1 (bevarer lydindstilling) og v2.
- Ukendte id'er filtreres, behov clampes til 0–100.
- Autosave efter handlinger, ved sceneskift og hvert 10. sekund.

## Assets

- Lagdelte SVG'er i `src/assets/character/`, `pets/`, `eggs/`, `furniture/`,
  `rooms/`, `town/`, `ui/`.
- Stil: flade farver, runde former, tydelige konturer, store øjne, pastelfarver.
- Rasteriseres ved belastning i moderat størrelse (karakter/kæledyr 384 px, æg
  256 px, ikoner 96 px, baggrunde 1280×720).
- Kæledyrsanimation laves med tweens (bob, hop, spis, sov, vip med halen).

## Risici

- **Mængden af grafik** er den største risiko. Afhjælpes med lagdelte SVG'er,
  tint i stedet for farvevarianter og en fast, enkel stil.
- **Hukommelse på tablets** ved mange rasteriserede SVG'er. Afhjælpes med
  moderate teksturstørrelser og lazy-load i 2C.
- **Indretning med touch** kan føles svært. Afhjælpes med grid-snap, store
  håndtag og tap-tap som alternativ til træk.
- **Behovsbalance** må ikke blive stressende. Der er ingen straf.
- **Navneindtastning** på tablet er bøvlet. Derfor vælges navn fra forslag.
